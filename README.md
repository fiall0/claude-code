# claude-code

A repository for [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) — Anthropic's agentic coding tool that lives in your terminal.

## Overview

Claude Code is an AI-powered coding assistant that understands your codebase and helps you write, debug, and improve code through natural language conversation.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or higher
- An [Anthropic API key](https://console.anthropic.com/)

### Installation

```bash
npm install -g @anthropic-ai/claude-code
```

### Usage

Navigate to your project directory and start Claude Code:

```bash
claude
```

## Configuration

Project-specific instructions for Claude Code are stored in `CLAUDE.md` at the root of the repository. Claude reads this file automatically when starting a session in this directory.
